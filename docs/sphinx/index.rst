ProjectKoios Ingestion API
==========================

This documentation describes the stable typed boundaries owned by the
Ingestion repository. It complements the decision records and schematics under
``docs/architecture``.

The words *configurable actionizer*, *projector*, *materializer*, *pipeline*,
*inventory reader*, *payload error*, and *identity error* have the narrow
meanings defined in the pages below. They are not interchangeable labels for
generic processing or storage operations.
