# `projectkoios.ingestion.transcript.reading.evidence`

Clean backend-neutral canonical reading evidence derived from exact typed producers. It preserves native/OCR streams, joins clean text with structured roles/order, retains visual/equation evidence and managed references, and exposes pure projection/source/equivalence actions.

The prototype modules and JSONL artifacts are capability-discovery evidence only, not compatibility contracts.
