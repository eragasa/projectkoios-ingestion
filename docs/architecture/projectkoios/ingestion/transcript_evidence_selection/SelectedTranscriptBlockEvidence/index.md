# `SelectedTranscriptBlockEvidence`

Immutable selected-block handoff containing transcript, page, root block, and
clean block-record identities; canonical order; separate clean indexed and
exact retained raw strings with SHA-256 digests; transformation evidence;
dehyphenation decision IDs; and an explicit clean-to-raw mapping basis. Its
identity binds the complete retained evidence.
