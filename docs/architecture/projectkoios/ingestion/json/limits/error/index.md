# `projectkoios.ingestion.json.limits.error`

This module defines `JsonLimitError`, the shared failure raised when JSON input,
projection, or serialization exceeds an explicit `JsonLimits` boundary, and
`JsonDocumentByteLimitError` for complete-document byte ceilings.
