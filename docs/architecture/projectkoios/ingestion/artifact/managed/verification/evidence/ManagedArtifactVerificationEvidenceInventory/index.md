# `ManagedArtifactVerificationEvidenceInventory`

Semantic immutable collection proving exact one-to-one successful verification coverage for a requested `ManagedArtifactReferenceInventory`. It rejects missing, extra, duplicate, stale, conflicting, unsorted, or over-limit observations and derives its own identity.

See the [implementation](implementation.md) and [schematic](schematic.md).
