# `projectkoios.ingestion.layout.annotation`

Immutable human and model-authored layout annotation evidence.

The package preserves authorship and authority boundaries: model output is not
human annotation, human review is optional and append-only, and neither path
authorizes publication or replaces the authoritative `PageLayoutResult`.
