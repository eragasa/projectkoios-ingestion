# `projectkoios.ingestion.layout.reading`

This package owns framework-neutral reading-layout evidence. Its `order`
subpackage verifies candidate orders against exact geometry and explicit native
block membership without claiming semantic knowledge. Its `evaluation`
subpackage deterministically aggregates already-normalized replica judgments
for exactly one candidate without selecting or correcting an order.

See [implementation](implementation.md), [schematic](schematic.md), and the
[structural path map](structural-path-map.md).
