# `projectkoios.ingestion.integrations.coco.layout.equation`

Deterministic projection of admitted COCO `Formula` detections into
recognition-ready equation candidate evidence and rendered display assemblies.

The package preserves detector, category-admission, render, annotation, pixel
geometry, source geometry, candidate, and assembly lineage. It does not
recognize an equation, establish transcription correctness, finalize page
layout, or grant publication authority.

See [implementation](implementation.md), [schematic](schematic.md), and the
[structural path map](structural-path-map.md).
