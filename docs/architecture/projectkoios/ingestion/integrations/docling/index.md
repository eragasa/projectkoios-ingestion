# `projectkoios.ingestion.integrations.docling`

Pinned optional Docling integrations that retain Koios contracts and authority
boundaries.

The initial integration exposes rule-based reading-order **candidate**
generation. It does not train a model, resolve semantic reading order, or grant
projection or publication authority.

See [implementation](implementation.md), [schematic](schematic.md), and the
[structural path map](structural-path-map.md).
